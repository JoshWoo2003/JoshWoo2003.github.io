\section{\faList~\textbf{Research Experience}}

\datedsubsection{\textbf{\fontsize{10.5pt}{12pt}\selectfont LooseLeaf: Enabling Serverless GPUs for Computational Notebooks}}{2025.09 -- 2026.09}
\role{Project Lead}{Advisor: Yue Cheng (UVA)}
\vspace{-1.0em}
\begin{itemize}
  \item Built LooseLeaf, a serverless GPU platform that allocates GPUs per notebook cell, acquiring a GPU only when a GPU cell runs and reclaiming it right after, instead of pinning one to the whole session.
  \item Characterized $\sim$5,000 real-world notebooks and showed that a GPU cell needs only a small part of the session state, which LooseLeaf derives by static analysis and loads into a GPU worker while the user edits.
  \item Designed a per-variable checkpoint store that preserves object sharing across variables, and a CUDA-safe import cache that forks GPU workers with their packages preloaded.
  \item Started 95--98\% of GPU cells within one second and cut GPU-hours by 43--70\% versus session-pinned GPUs and by 32--55\% versus NotebookOS (ASPLOS'26).
\end{itemize}
\vspace{-1.0em}

\datedsubsection{\textbf{\fontsize{10.5pt}{12pt}\selectfont ZenFlow: Enabling Stall-Free Offloading for LLM Training}}{2024.10 -- 2025.08}
\role{Lead Implementer}{Advisors: Yue Cheng (UVA) and Dong Li (UC Merced)}
\vspace{-1.0em}
\begin{itemize}
  \item Co-developed ZenFlow, an offloading framework for LLM fine-tuning that updates important gradients on the GPU right away and applies the rest asynchronously on the CPU, reducing GPU stalls.
  \item Led the $\sim$11K-line implementation on DeepSpeed, including gradient selection across sharded GPUs, and proposed a column-major gradient layout that makes channel-wise selection efficient.
  \item Achieved up to 5$\times$ speedup, 85\% fewer GPU stalls, and 72\% lower cloud GPU cost with no accuracy loss.
\end{itemize}
